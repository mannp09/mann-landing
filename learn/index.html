Learning

Teach yourself AI by finishing one real thing.

Most AI material explains. This is built the other way round: pick one thing worth having, build it end to end, and learn the tools on the way. Everything here is a method I have actually run, written down after it worked rather than before.

The AI storybook workbook

The project I would start with. A storybook about the people in your life, illustrated and published, in 4 steps. Holding one character steady across every page is the hard part, so the method is built around that.

01

Outline it

Write how the story goes. Short is fine. This part stays yours.

02

Let AI write it

Give the outline to a model and let it write the pages.

03

Find the style

Use a continuity keeping image tool, let it write a prompt per scene, then let it compile the pictures with the story.

04

Put it online

One file, one link, and it is shareable.

3 collections have come out of this method, and 1 of the 3 was built by someone outside my own work. See the 3 examples playing on the home page, or take the 2 page guide as a PDF.
