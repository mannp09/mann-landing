What I've Built

Grouped by domain. Each is something I designed, built, and shipped. Most are live or in daily use.

1AI Assisted Financial Markets Tool
A decision support system for reading market conditions before taking risk.
Multi Layer Market ReadLive
Analyzes the macro environment, sector rotation, and the futures instruments that lead it, layering structure, macro context, and order flow into a single graded read of how favorable conditions are for putting risk on.
Self Rendered Charts and a Grading FrameworkPython · Next.js
Pulls OHLCV bars from the Yahoo Finance API and renders its own candles rather than screenshotting a terminal, applies a consistent checklist based rubric, and logs every read with its outcome, so the framework can be measured and improved, not just trusted.
Live Market Data LayerYahoo Finance · Robinhood MCP
Two sources wired behind one interface: Yahoo Finance for historical and intraday bars, and a Robinhood MCP server for real time quotes, option chains, fundamentals, technical indicators and screener runs. Every figure is reconciled against the source export before it reaches a chart or a document.
2Agentic Systems and Automation
The infrastructure that lets AI run real, repeatable work with the human in control.
The Exocortex, a Persistent AI Operating SystemDaily Driver
An external memory and meta agent system: domain agents, self improving scheduled loops, and a witness layer that surfaces and records but never decides for me. It keeps state coherent across sessions and compounds judgment instead of rebuilding it each time.
Connectors and MCP ServersGmail · Drive · Calendar · Robinhood
Email, Drive and Calendar automations built once as playbooks that run on a new account by changing a label, not rewiring the workflow. The same pattern drives market data MCP servers, so a quote, a fundamental and a screener result arrive through one contract.
Local Speech to Text ToolFaster Whisper
